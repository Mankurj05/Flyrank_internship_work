# FlyRank AI Capstone

An AI-assisted development capstone project built as part of the internship track.

## Project Overview
This repository serves as the central hub for the FlyRank AI Capstone project. The development process leverages advanced AI assistants (e.g., Claude Code, Cursor, and Antigravity) to design, implement, and verify applications built on a modern web stack.

## Tech Stack
- **Core Engine:** Node.js (LTS)
- **Frontend:** HTML5, CSS3 (Vanilla), and Vanilla JavaScript
- **Conventions:** Conventional Commits 1.0.0

## Developer Guide & Conventions
This repository is configured for optimal AI-assisted pair-programming. Please adhere to the following rules:

- **CLAUDE.md:** Consult the [CLAUDE.md](file:///c:/Users/mayan/Downloads/flyrank_ai/CLAUDE.md) file for build, run, test commands, and coding styles.
- **Commit Format:** Every commit MUST follow the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) specification. For example:
  - `feat: add user authentication`
  - `fix: resolve responsive layout shift`
  - `docs: update setup documentation`

## Getting Started
To run the project locally:
1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd flyrank_ai
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
